# Buffalo Franquicias · propuestas web

Cuatro prototipos para el rediseño de la landing de captación de franquiciados de Buffalo Waffles (buffalofranquicias.com).

**Ver en línea:** https://thomas-sbf.github.io/buffalo-franquicias-propuestas/

| Prototipo | Concepto |
|---|---|
| [A4-1 · De la calle a tu local](03-prototipos/A4-1-de-la-calle-a-tu-local/) | La ruta desde un waffle en kraft hasta tu inauguración, con el configurador «Arma tu Buffalo» |
| [A4-2 · La Crew](03-prototipos/A4-2-la-crew/) | Fanzine con cartas de franquiciados, álbum de regiones y test «¿Eres Buffalo?» |
| [A5-1 · El negocio en vivo](03-prototipos/A5-1-negocio-en-vivo/) | Tablero del inversionista: cada número con su fuente y un simulador de inversión |
| [A5-2 · Bloques de sabor](03-prototipos/A5-2-bloques-de-sabor/) | Una carta de 7 capítulos con un color por sabor y postulación conversacional |

## Contenido
- `01-research/`: benchmark de 20 sitios de franquicias y reporte de tendencias web 2026.
- `02-design-system-web/`: design system web v2 (tokens, componentes, voz para inversionistas, pendientes del cliente).
- `03-prototipos/`: los 4 prototipos, cada uno con su `RATIONALE.md`.
- `04-revision/informe-final.md`: evaluación, recomendación y decisiones pendientes.

Son maquetas para revisión interna: los formularios no envían datos y las cifras marcadas en rosa están pendientes de validar con Buffalo Waffles.
